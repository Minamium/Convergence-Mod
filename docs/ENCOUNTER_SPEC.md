# Encounter Specification

The active first-Raid specification moved to [`encounters/first-severance/ENCOUNTER_SPEC.md`](encounters/first-severance/ENCOUNTER_SPEC.md).

The previous `Third Severance` seven-phase concept is no longer the implementation target. Part Break, Targeted Line/Bait, Personal Effigies, Split Reality, Last Stand, multipart Crown/Wings/Heart Casing, and exposure damage quotas are preserved only in the [`First Severance` backlog](encounters/first-severance/BACKLOG.md).

Current source under `Content/Encounters/FirstSeverance` implements the playable development encounter. Use the [current feature spec](encounters/first-severance/ENCOUNTER_SPEC.md) for behavior and [Status](STATUS.md) for evidence; legacy plans are historical.
