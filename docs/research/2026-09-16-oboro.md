# Oboro: API and comparison boundary

Target: installed tModLoader2026.07.3.0/Terraria1.4.4.9, Calamity2.2.4, .NET8/C#12. Official tML stable API pages and the installed XML were inspected for GetIncomingStrikeModifiers, HitModifiers.ToHitInfo, StrikeNPC/SendStrikeNPC, GetWeaponArmorPenetration, GlobalNPC extra AI and BuffDrawParams. Compilation validates those installed signatures, not actual multiplayer behavior.

The pinned [PlayerLoader](https://github.com/tModLoader/tModLoader/blob/666f69962d3bdffde54fc14025f02634965b4e7c/patches/tModLoader/Terraria/ModLoader/PlayerLoader.cs) shows item permission/modifier/on-hit hooks forwarding to generic player hooks. [CombinedHooks](https://github.com/tModLoader/tModLoader/blob/b789d6285cb36fc28b568d4e44848a5c6c6f021a/patches/tModLoader/Terraria/ModLoader/CombinedHooks.cs) was read at the current1.4.4 commit; the installed assembly accepts the same API calls. [Native hit modifier API](https://docs.tmodloader.net/docs/stable/struct_n_p_c_1_1_hit_modifiers.html) and [NPC API](https://docs.tmodloader.net/docs/stable/class_n_p_c.html) document incoming modifiers and finalized hits. tML is MIT; API behavior only, no external implementation copied. Existing [shared-buffer evidence](FIRST_SEVERANCE_SLICE3_APIS.md) governs decoding.

Official Calamity public1.4.4 remained `1a8cebd27ec5615316b78f71973446b5528d2b78` when inspected. That source reports2.2.2, not the installed2.2.4. [Earth](https://github.com/CalamityTeam/CalamityModPublic/blob/1a8cebd27ec5615316b78f71973446b5528d2b78/Items/Weapons/Melee/Earth.cs) has base damage4200 and use time42; [EarthHoldout](https://github.com/CalamityTeam/CalamityModPublic/blob/1a8cebd27ec5615316b78f71973446b5528d2b78/Projectiles/Melee/EarthHoldout.cs) uses an offset expanding hitbox, extra hits and meteor effects. Its blade bounding extent informs Oboro's560px initial reach; that is a tuning inference, not a measured2.2.4 reach/DPS result. Oboro's base8400,24/24/42-tick combo and2.2× third cut, marks and requested percentage DoT target higher endgame output. Equipped Earth-vs-Oboro DPS remains a user playtest.
