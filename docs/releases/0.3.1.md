# Convergence 0.3.1 — Public Playtest

This is a development **prerelease**, not a finished or stability-certified release.

## Content and changes

- **Requiem of the Hollow Doll — initial prototype complete.** Face **Lacrimosa — The Bound Heart** through preparation, P1/P2/P3 and Final survival. Includes Stack/Spread, instant teammate revival, treasure-box class weapons and the craftable Doll companion.
- **Ghost Samurai — in development.** An independent summoned boss; not part of the completed Doll prototype. Rewards, balance and lifecycle behavior remain unfinished.
- Compared with 0.2.78, this release changes the version, public naming/tooltips, publication materials and documentation workflow. It preserves combat code, gameplay timing, HP, loot, music, effects and **protocol37**. Internal `FirstSeverance` / `NullCantor` / `DollCovenant` IDs remain stable; no save migration is introduced.

## Playtesting and installation

Requires **Calamity Mod 2.2.4** and **Luminance 1.0.14**, plus the dependencies they request. Tested baseline: **tModLoader 2026.07.3.0 / Terraria 1.4.4.9**, Windows. See the [version matrix](../VERSION_MATRIX.md) for the compatibility bounds; later versions/other platforms are not certified here.

**Multiplayer is preferred (2–4 players); solo activation is enabled** for this owner-approved public-test channel. Solo reuses the development party workload and is not a separately balanced mode. Minions are not Raid participants. Everyone must use the same Convergence build.

Back up worlds/characters and use test saves. Obtain Foundation Core, Theater Doll and Resuscitation Kit through an item spawner such as Cheat Sheet; they do not yet have normal recipes. Place the pedestal with clear space, hold Theater Doll and click it, then every player marks Ready. The kit revives a Downed ally without being consumed; the recipient cannot receive another revival for 60s. One solo Down, or all party members Down, ends the Raid.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3798073077) is the normal distribution route; the owner updates it separately after this GitHub release. For a manual GitHub install, place the `.tmod` in the tModLoader save directory's `Mods` folder with the game closed; remove conflicting local copies and reload Mods. The release checksum identifies the exact package. Do not copy dependency binaries from this repository; subscribe to their official distributions.

## Verification and known limitations

- Baseline gameplay evidence: one [0.2.78 solo victory](../evidence/2026-09-14-playtest-0278.json), 240.65s, Stack19/19 and Spread22/22, no Down/revive; 24 weapon cues / 48 actual-playback diagnostics. This is not multiplayer or subjective listening certification.
- Consult the GitHub release's `build-evidence.json` and `SHA256SUMS.txt` for the exact package, source commit and executed checks. The package audit checks version, source stability, locale parsing, exclusions and unchanged combat/asset bytes; compilation is not a runtime playtest.
- **Known shutdown issue:** `GhostSamuraiContainmentSystem.OnWorldUnload` can throw `IndexOutOfRangeException` even without summoning Ghost Samurai. Latest logs also contain native tile-stream shutdown warnings and a later SubworldLibrary EOF; their causal relationship is unproven. No fix or reliable exit/re-entry is claimed in this release.
- **Not run on the exact 0.3.1 package:** owner GUI reload/load and repeat entry/exit, full Dedicated Server / 2–4-player matrix, revival/rejoin/latency checks, latest display-scale/reduced-effects/audio-mix and performance review. A playable prototype is not completion of the production release gate.
- Strong flashes, screen shake and sound are present; reduced-effects options are available. Balance, compatibility and future save compatibility remain provisional. No unsupported FPS or load-resilience claim is made.
- Production administration checks are not certified: GitHub secret scanning/push protection and private vulnerability reporting were disabled at the read-only check, and an independent off-device asset backup was not verified. This task does not silently change repository settings or upload originals. Public reports use Issues; never post credentials or sensitive security details there.

Please [report issues](https://github.com/Minamium/Convergence-Mod/issues) with version, player count, enabled Mods and reproduction steps. Redact personal information; do not post whole logs/saves by default.
